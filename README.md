# 8人制阵容编辑 MVP

第一版聚焦主流程：微信接龙粘贴导入、组织者确认名单、三队长选人、横屏阵容拖拽和文字战术板。

## 功能范围

- 接龙导入：识别 `1: 姓名`、`门将张亮`、24 人后的候补。
- 名单确认：组织者可手动标记或取消 GK。
- 队长设置：红、绿、白三个队长由组织者指定，队长自动进入本队。
- 选人：普通球员顺序和门将顺序都可配置，GK 只能最后选，每轮 60 秒，超时随机选人。
- 阵容：支持 3-3-1、2-3-2、3-2-2 预设阵型和自由拖拽。
- 战术板：提供进攻箭头、防守回收、区域框、文字标注和橡皮擦，教练可在球场上自由布置。
- 战术保存：支持撤销、复制当前队战术 JSON、导入战术 JSON、清空标注。
- 教练说明：右侧保留工具使用说明，不预设具体战术答案。

## 后续预留

- 微信授权登录和角色权限。
- 多人实时同步选人。
- 比赛记录：第 X 节、第几分钟、进球人、助攻人、比分。
- 榜单：球队积分、个人积分、射手榜、助攻榜、门将榜。
- 阵容图和赛后榜单图导出。

## 打开方式

直接打开 `index.html` 即可使用当前静态 MVP。
